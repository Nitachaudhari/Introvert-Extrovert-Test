# K.I.E.I. (KUNDU INTROVERSION EXTRAVERSION INVENTORY)
## Authoritative Source Extraction & Psychometric Specification Document

---

### 1. Test Name & Author
- **Full Test Name**: Kundu Introversion Extraversion Inventory
- **Abbreviation**: K.I.E.I.
- **Author**: Dr. Ramanath Kundu, M.Sc., Ph.D.
- **Affiliation**: Department of Psychology, Calcutta University (University College of Science & Technology, 92, Acharya Prafulla Chandra Road, Calcutta-700 009)
- **Copyright**: 1976 by Dr. Ramanath Kundu. All rights reserved.
- **Cultural Standardization**: Standardized on Indian socio-cultural population.

---

### 2. Number of Questions & Section Breakdown
- **Total Items**: 70 items divided across 5 distinct blocks.
- **Block A**: Items 1 to 11 (11 items) — 4 response options per item. Focus: Objective situations/activities.
- **Block B**: Items 12 to 28 (17 items) — 5 response options per item. Focus: Introspective items.
- **Block C**: Items 29 to 42 (14 items) — 3 response options per item. Focus: Preference of one activity over another.
- **Block D**: Items 43 to 56 (14 items) — 3 response options per item. Focus: Objective activities regarding oneself.
- **Block E**: Items 57 to 70 (14 items) — 2 response options per item ('Yes' / 'No'). Focus: Introspective forced choice.

---

### 4. Authoritative Scoring Method

1. **Answer Sheet Grid Structure**:
   - The original physical answer sheet features pre-arranged rows corresponding to item-response weights.
   - For each block, rows correspond to multipliers:
     - **Block A**: 4 rows with weights $\times 1, \times 2, \times 3, \times 4$.
     - **Block B**: 5 rows with weights $\times 1, \times 2, \times 3, \times 4, \times 5$.
     - **Block C**: 3 rows with weights $\times 1, \times 2, \times 3$.
     - **Block D**: 3 rows with weights $\times 1, \times 2, \times 3$.
     - **Block E**: 2 rows with weights $\times 1, \times 2$.
2. **Direction of Scoring**:
   - High score = **Introversion**
   - Low score = **Extraversion**
3. **Raw Score Range**:
   - Minimum possible score = **70**
   - Maximum possible score = **241**
4. **Item Classification for Direction**:
   - Items with negative answer showing introversion vs positive answer showing introversion are mapped per Table 2 and Table 3 of the manual.
